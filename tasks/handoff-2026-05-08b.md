## What shipped

### 1. /moderate — SUSPEND/DELETE layout fix
`globals.css` forces `select { width: 100% }` site-wide. The SUSPEND `<select>` had
no explicit width, so it filled the full row even with `width: auto` — and when it
wrapped to a new flex line it stretched wall-to-wall, pushing DELETE below it.
Fix: `width: 'auto'` on the select, and wrapped Suspend + Delete in an inner
`<div style={{ display:'flex', gap:'6px' }}>` so they're a single flex child.
Commits: `9045492`, `2cc1a1d`.

### 2. /moderate — Pages Visited on activity dossier
`app/moderate/users/[userId]/activity/page.tsx` now fetches `visitor_logs` (last 20
rows + total count) in the same `Promise.all`. Renders at the bottom of the dossier:
visit number, path, IP hash, timestamp, total count.
Commit: `b495cea`.

### 3. /moderate — per-user Email button
`<a href="mailto:${u.email}">` rendered between Message and Characters on each user
row, only when `u.email` is non-null.
Commit: `d00c5ac`.

### 4. Signup anti-spam: honeypot + consonant-run username check
Triggered by first confirmed spam account: `wEpAfxklFqFikMBdndLxo`.
- Honeypot: hidden `<input name="website">` off-screen (not `display:none`, which
  bots detect). If populated on submit, silently redirect — no error exposed.
- `looksRandom(username)`: blocks usernames with 6+ consecutive consonants in a row
  (y/Y counted as vowel so "Grumpy" etc. pass).
Both checks run before Turnstile; they're the first-line defense when the widget
is unavailable.
Commit: `6e49091`.

### 5. Cloudflare Turnstile invisible CAPTCHA
Full implementation in `app/signup/page.tsx`:
- Next.js `<Script>` loads `api.js?render=explicit` and calls `mountTurnstile()` onLoad.
- Widget in `size: 'invisible'` Managed mode (auto-solves on render).
- Token cached in `cachedTokenRef` via the `callback`. `widgetErroredRef` tracks errors.
- On submit: reads the cached token, POSTs to `/api/auth/verify-turnstile`.
  - If widget errored (domain mismatch, ad blocker, CDN issue): fail open.
  - If server returns non-OK on a real token: hard block, reset token.
- `app/api/auth/verify-turnstile/route.ts`: new POST route, validates against
  Cloudflare siteverify API. Reads `TURNSTILE_SECRET_KEY` from env (server-only).
  Fails open in non-production when secret not configured.
- Button shows "Verifying..." while `submitting` is true.
Commits: `3b14a02`, `54c3402`, `315570c`, `3d95be2`.

### 6. Cloudflare Turnstile hostname registration (manual, done in Cloudflare UI)
Added to Hostname Management on the "The Tapestry" Turnstile widget:
- `localhost`
- `thetapestry.distemperverse.com`
- `vercel.app` (Cloudflare UI rejects wildcards; parent domain covers all subdomains)

This resolves Sentry error code 400020 ("hostname not registered").

**Env vars required in Vercel:**
- `NEXT_PUBLIC_TURNSTILE_SITE_KEY` — the site key (public, baked at build time)
- `TURNSTILE_SECRET_KEY` — the secret key (mark Sensitive in Vercel)

Both are visible in Cloudflare > Application Security > Turnstile > The Tapestry widget.
