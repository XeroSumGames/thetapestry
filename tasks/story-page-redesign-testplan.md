# Story Page Redesign - Test Plan

## URL
`thetapestry.distemperverse.com/stories/<any-campaign-id>`

## Steps

1. Open a story page as a **player** (not GM)
2. Confirm topbar shows "← My stories" on left and "Campaign lobby" on right
3. Confirm hero shows setting chip + "Player" role chip, campaign title, description (if set), and Launch + Leave buttons
4. Confirm left column shows "My survivor" section with avatar initials, select dropdown, Assign button
5. Confirm left column shows "Create new survivor" row (Backstory generation / Quick character / Random character)
6. If campaign has a setting with pregens: confirm pregen cards grid below create row
7. Confirm right column shows party members with avatar initials, name, GM chip (GM row), character name, Msg button, joined date
8. Confirm right column has Invite section with link, code, Copy link button
9. Confirm footer shows "Joined <date>" on left, "War stories / Sessions / Community" on right
10. Report what you see

---

11. Open same story page as the **GM**
12. Confirm hero shows "Game master" role chip (amber), Launch button, "GM tools ▼" button
13. Confirm left column shows "Story settings" with Story name, Hook, Default map style, Map center, Save changes
14. Edit story name, click Save changes - confirm ✓ Saved appears and hero title updates
15. Click "GM tools ▼" button in hero - confirm GM Tools section expands at the bottom
16. Confirm GM Tools shows action bar (GM Notes, Snapshot, Publish, Delete, GM Kit)
17. Click "▲ collapse" to collapse - confirms it folds back
18. Confirm right column shows same party + invite as player view
19. Report what you see
